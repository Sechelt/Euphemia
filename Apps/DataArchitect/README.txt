License

This is an Alpha release. This means that it is not feature complete and probably has some bugs.
This release is free and without warranty. The hope is that;

1. some folks will find it useful even as an Alpha
2. early feedback will lead to a better product 

Requirements

This is not a proper install package - that will come. For now it is a binary which 
should work on any recent Linux-64 platform - with a few requirements met.

1. Qt v5
2. sqlite3
3. unixODBC

Feedback

The application has a toolbutton for invoking a browser with the following url;

https://www.codebydesign.com/mantisbt

Anyone having trouble running the binary can submit a bug/request by using that 
URL in their web browser.
